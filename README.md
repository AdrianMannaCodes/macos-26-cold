# MacOS 26.0.1 Cold

A browser-based MacOS 26.0.1 Cold emulator with Tahoe-style glass UI and a Golden Gate theme.

- 16 apps (Finder, Safari, Mail, Messages, Notes, TextEdit, Calculator, Terminal, Calendar, Clock, Photos, Music, System Settings, Online Disk, App Store, About)
- Local Apple ID sign-in (no phone number needed), stored in browser localStorage
- Online Disk: a browser-stored cloud drive for files
- Mouse, trackpad, and touch support

Live site: https://adrianmannacodes.github.io/macos-26-cold/
